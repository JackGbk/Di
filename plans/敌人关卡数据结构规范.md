# 敌人 / 关卡数据结构规范（关卡类型标签系统）

## 1. 背景与目标

现有敌人与关卡定义分散在 [`js/data.js`](../js/data.js) 四张表中：

| 数据表 | 位置 | 职责 |
|---|---|---|
| `ENEMY_TYPES` | data.js:1241 | 11 种敌人的数值倍率 / 技能 / 站位 |
| `LEVEL_TRAITS` | data.js:1273 | 15 关的主题名 / 图标 / 怪数 / 构成 / 难点文案 |
| `MINI_BOSSES` | data.js:1316 | 每关小 Boss 机制 |
| `BIG_BOSSES` | data.js:1350 | 第 5/10/15 关大 Boss 机制 |

问题：**"每关类型"目前只是 `diff` 字符串里的文案**，没有结构化字段，界面无法显示类型徽章，引擎/图鉴/成就也无法按类型区分。

目标（本期范围，用户已确认方案②）：
1. 新增 `LEVEL_TYPES` 类型字典（15 个类型，每关唯一）；
2. `LEVEL_TRAITS` 每关加 `type` 字段；
3. 难度选择屏显示**类型徽章**（悬停显示类型应对提示）；
4. 难点说明（💰 tooltip）增加**类型化应对行**。

## 2. 数据结构规范

### 2.1 关卡类型字典 `LEVEL_TYPES`

```js
/* 键 = 类型 id（英文小写），每关唯一使用一个 */
const LEVEL_TYPES = {
  skirmish: { icon:'⚔️', name:'遭遇突袭', tip:'类型通用应对提示（一句话）' },
  ...
};
```

字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `icon` | string(emoji) | ✅ | 徽章图标，与 `LEVEL_TRAITS.icon`（关卡主题图标）并列显示 |
| `name` | string | ✅ | 类型名（2~5 字），徽章正文 |
| `tip`   | string | ✅ | **类型化难点说明**：该类型的通用应对手法，悬停徽章/💰 时显示 |

类型 id 分配（15 关一一对应，保证"每关类型不同"）：

| 关卡 | type id | 类型名 | 分配理由 |
|---|---|---|---|
| 1 | `skirmish` | 遭遇突袭 | 新兵试探关，4 脆皮小兵 |
| 2 | `armor` | 铁壁高甲 | 2 蛮兵高甲推进，考破甲 |
| 3 | `fury` | 狂暴快攻 | 狂战士攻高皮脆越伤越狂 |
| 4 | `elite` | 词缀试炼 | 精英随机词缀组合 |
| 5 | `overlord` | 熔岩霸主 | 第一个大 Boss（机制关） |
| 6 | `assassin` | 切后突袭 | 疾行者+狙击手直奔后排 |
| 7 | `siege` | 要塞攻坚 | 少怪高减伤（石肤巨人），考单点 |
| 8 | `curse` | 亡语诅咒 | 死亡爆炸 + 流血，考集火顺序 |
| 9 | `swarm` | 人海战术 | 满编 5 人海，考 AOE |
| 10 | `summon` | 深渊召唤 | 大 Boss 召唤 + 后排奶/法 |
| 11 | `tempo` | 疾风决斗 | 攻速节奏对决 |
| 12 | `blood` | 嗜血续航 | 吸血+流血持久战，考爆发 |
| 13 | `ritual` | 暗影仪式 | 双奶+噬魔，考断奶 |
| 14 | `onslaught` | 洪流总攻 | 全输出满编，考开局应对 |
| 15 | `coronation` | 腐化加冕 | 最终关混合机制 |

### 2.2 关卡定义 `LEVEL_TRAITS[关卡]`（改动最小化）

```js
1: { type:'skirmish', icon:'🌿', name:'林间前哨', count:4,
     diff:'本关具体的难点描述（保留原有人工文案）',
     mobs:['minion','minion','minion','minion'] },
```

| 字段 | 变化 | 说明 |
|---|---|---|
| `type` | 🆕 新增，必填 | 引用 `LEVEL_TYPES` 的键；未知 id 时界面需容错（不显示徽章，不报错） |
| `icon/name/count/diff/mobs` | 不变 | `rollEnemyCount()` / `rollEnemyTypes()` 逻辑不动 |

分层规则：**`type.tip` 讲"这类关怎么打"（通用），`trait.diff` 讲"这关具体有什么"（个别）**，两行同时显示、互不替代。

### 2.3 敌人定义 `ENEMY_TYPES`（本期不改，规范先行）

现有字段 `name/gold/emoji/mult/skills/pos` 保持不变。后续扩展预留（见 §5）：

```js
{ ..., role:'后排单点',          // 可选：图鉴/介绍栏用的职责标签
      ai:{ targeting:'lowestHp' } } // 可选：技能选目标偏好（需引擎支持后启用）
```

## 3. 界面改动

### 3.1 难度选择屏（[`Rogue.renderDiff()`](../js/rogue.js:59)）

1. 顶部主题行加类型徽章（💰 悬停已有 attr 转义可复用）：
   `🧭 本关主题 · 🌿林间前哨` → `🧭 本关主题 · 🌿林间前哨 [⚔️ 遭遇突袭]`
   徽章 `title` = `type.tip`（悬停显示类型应对提示）。
2. 💰 tooltip（`tipText()`）在"⚠️ 难点"之前插入一行：
   `🏷️ 类型：⚔️ 遭遇突袭 — <tip>`
3. 其余（敌人构成 / Boss 词条 / 预计奖励行）不动。

### 3.2 帮助文本（[`UI.info`](../js/ui.js:519)）

在"💰 小图标…悬停查看本关主题难点"说明处补一句：关卡顶部的 🏷️ 类型徽章标明本关玩法类型，悬停可见应对提示。

### 3.3 样式（css/style.css）

新增 `.lv-type` 徽章（蓝底胶囊、金色悬停、`cursor:help`），紧邻 `.diff-boss` 规则块放置；不引入滚动条、不影响既有布局。

## 4. 容错与兼容

- `LEVEL_TYPES[trait.type]` 取不到 → 徽章与类型行整体跳过（旧存档 / 手误不断屏）；
- `trait` 不存在（第 15 关外的越界）→ 维持现状"无主题"分支；
- 存档不含关卡类型（类型是关卡静态数据，不入 Save）；
- 不改动 `rollEnemyTypes/rollEnemyCount/makeEnemy`，战斗数值零影响。
